# CyberDravida Security Awareness Training

A comprehensive and interactive platform designed to educate users on cybersecurity best practices. This application provides engaging training modules, realistic phishing simulations, and streamlined incident reporting tools to enhance organizational security posture.

## 🚀 Features

- **Interactive Learning Modules**: Structured lessons covering essential security topics.
- **Phishing Simulations**: Real-world scenarios to test and improve user awareness.
- **Incident Reporting**: Easy-to-use interface for reporting potential security incidents.
- **Dashboard & Analytics**: Track progress, view completion rates, and monitor training status.
- **Certificate Generation**: Earn certificates upon successful completion of training courses.
- **Resource Library**: Access to additional security guides and documentation.

## 🛠️ Tech Stack

This project is built with a modern frontend stack ensuring performance and scalability:

- **Frontend Framework**: [React](https://react.dev/) with [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend Integration**: [Supabase](https://supabase.com/)

## 🏁 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/cyberdravida/Security-Awareness-Training.git
   cd cyberdravida-learn-main
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:8080` to view the application.
